多瀏覽器深色模式切換

Windows 可攜式工具：把瀏覽器介面與網頁內容切成深色模式，也能還原成系統預設外觀。

Windows 10／11 · .bat 批次檔 · 免安裝、免系統管理員權限

下載 ChromeDarkMode.bat

使用方式

  1. 點上方按鈕下載 ChromeDarkMode.bat（純文字檔，可先用記事本打開檢查內容）。
  2. 雙擊執行。
  3. 選擇單一瀏覽器，或一次套用到全部支援的瀏覽器；也可以個別或全部還原。

執行時會先關閉所選的瀏覽器再套用設定，請先存好未送出的表單與內容。

支援的瀏覽器與需求

  • Google Chrome、Perplexity Comet、Microsoft Edge
  • Internet Explorer（該 Windows 版本仍有 IE 時）

需要 Windows 10 或 11、至少一個支援的瀏覽器、Windows PowerShell 5.1 以上（Windows 內建）。

會更新目前 Windows 帳號下既有的瀏覽器設定檔；還原時只移除本工具加上的深色模式設定，其他自訂設定會保留。

瀏覽器大改版後若效果改變，請重新執行一次確認。
