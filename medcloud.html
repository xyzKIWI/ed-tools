雲端藥歷整理小幫手

Edge／Chrome 擴充功能：整理健保雲端目前已載入的西醫用藥、檢驗、影像及病理、手術、出院病摘與過敏紀錄。輸出供核對，不取代正式病歷、原始報告與臨床判斷。

版本 1.6.0 · 2026-10-28 · Edge／Chrome

下載擴充功能 ZIP

安裝與更新

  1. 完整解壓縮 ZIP，保留在固定的本機資料夾。
  2. 開啟 edge://extensions 或 chrome://extensions，啟用「開發人員模式」。
  3. 先停用舊版，按「載入解壓縮」，選 extension 資料夾，確認版本為 1.6.0；不要同時執行兩版。
  4. 重新開啟健保雲端頁面；登入與卡片驗證照平常流程操作。

更新時解壓縮到新的資料夾，舊版資料夾保留當備份；停用或移除舊版後再載入新版，載入後重新整理健保頁面。要回復時，停用新版、重新載入舊版資料夾即可。

彙整病歷

  1. 依院所平常流程完成授權查詢，確認是目前這位個案。
  2. 核對各頁日期範圍與篩選；要納入半年內檢查，原頁也要查出至少半年資料。
  3. 回到「摘要」頁，按「彙整病歷」；程式會依序讀取六區資料，必要時開啟原頁報告或病摘。
  4. 完成後先核對每區狀態、筆數、未完成警示與預覽，再複製需要的內容。
  5. 面板右上角 −／+ 可隨時最小化或還原。
  6. 換個案、新查詢或登出後，請重新整理頁面，不要沿用先前結果。

資料範圍：檢驗（抽血／驗尿）最近三個曆月；影像及病理最近六個曆月；西醫用藥與出院病摘三個月；手術不限日期；過敏依原頁查詢範圍。

未完成、逾時或未確認不等於沒有病史；過敏空白不等於 NKDA。翻頁期間不要自行切換病人、排序或修改篩選。

隱私與常見狀況

擴充功能不主動上傳、不用瀏覽器儲存區保存結果。複製內容會進入剪貼簿；下載的 JSON 屬醫療資料，請依院內規範保管與清除。

沒有整理按鈕：確認網址在 medcloud2.nhi.gov.tw/imu/、擴充功能已啟用，再重新開啟該頁。

某區未完成或筆數不完整：保留警示，回原頁核對日期、篩選與分頁；未載入的資料不會自動補齊。

回報問題時提供版本、頁籤名稱、匿名筆數與錯誤狀態即可，不要附真實個案截圖或報告內文。
