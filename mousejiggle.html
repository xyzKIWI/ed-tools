MouseJiggle 滑鼠防閒置工具

輕量、免安裝的 Windows 滑鼠防閒置工具，提供 Normal／Zen 模式、系統匣選單、淺色／深色介面及選用的開機啟動。

Windows 10／11 · 需 .NET Framework 4.8 · 免安裝、免系統管理員權限

下載可攜版 ZIP

使用方式

  1. 下載並解壓縮 MouseJiggle.zip。
  2. 執行 MouseJiggle.exe；程式會立即以 Zen 模式開始，預設每 50 秒一次。
  3. 用 Start Jiggling／Stop Jiggling 開始或停止。
  4. 選 Normal 或 Zen，間隔可設 1–60 秒，變更立即生效。
  5. 勾選 Start with Windows (minimized)，Windows 登入時會自動啟動並縮到系統匣；取消勾選即移除。

Zen：防止閒置但游標不會動。Normal：游標每次小幅來回移動 4 px。

按右上角 X 或 Alt+F4 只會縮到系統匣；要真正結束，請用視窗或系統匣選單的 Exit。

設定與注意事項

設定存在 EXE 旁邊的 MouseJiggle.ini（模式、秒數、深淺色）。如果移動了 EXE 的位置，請把開機啟動取消再重新勾選一次。

程式不使用網路、不安裝服務、不記錄鍵盤或滑鼠內容，也不要求提升權限。

請依院內資訊安全與電腦使用規範使用。
