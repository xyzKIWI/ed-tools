KMU 體系驗證碼填入

資訊室核准測試用 Chrome 擴充功能：在 KMU 體系登入頁於瀏覽器本機辨識 4 碼驗證碼並填入。

版本 1.3.2 · 2026-11-23 · private repo · 下載需 GitHub 授權

前往授權下載頁

只有獲授權的 GitHub 帳號能開啟下載頁。請勿轉傳安裝包或用於未經核准的網站。

第一次安裝

  1. 從授權下載頁下載最新版 ZIP，解壓到固定資料夾；Kiwi 本機固定使用 /Users/kiwi/kiwi_cc/kmu-captcha-fill。
  2. 網址列輸入 chrome://extensions，開啟右上角「開發人員模式」。
  3. 點「載入未封裝項目」，選擇含有 manifest.json 的資料夾。
  4. 重新整理已開啟的登入頁。

支援範圍

內建網域：kmuh.org.tw、kmu.edu.tw、kmugh.org.tw、kmsh.org.tw、kmch.org.tw。

只有同時偵測到驗證碼圖片與輸入欄時才會動作。擴充功能只填入驗證碼，不會按下登入。

加入獲授權的 HTTPS 測試網域

  1. 點擊擴充功能圖示，在「允許網域」只輸入 HTTPS 網站的網域名稱，例如 example.org.tw；不要輸入 https://。
  2. 按「加入」，確認 Chrome 權限提示只包含該網域及其子網域。
  3. 重新整理登入頁；不再使用時，回到彈窗按「移除」。

只可加入已獲資訊室或網站管理者核准的 HTTPS 測試網域。完整網址、路徑、port、萬用字元、IP 與 localhost 都不接受。

隱私與安全

  • 驗證碼只在瀏覽器本機辨識，不傳送到外部服務。
  • 不讀取、不保存帳號或密碼。
  • 不自動送出登入表單，使用者仍需自行確認。
  • 自訂網域需由 Chrome 額外核准網站權限。

更新與排錯

更新時保留同一個固定資料夾，替換裡面的檔案後，到 chrome://extensions 按「重新載入」，再重新整理登入頁。

沒有自動填入時，先確認頁面確實有 4 碼驗證碼圖片與輸入欄；自訂網域另需確認網站權限仍有效。
